Install

  1. Tap Download the app and wait for the bar to finish.
  2. Open the file from your Downloads.
  3. When Android asks, allow installs from this browser or file app.
  4. If Play Protect warns about an unknown app, choose Install anyway. This is a sideloaded build and Google Play has not reviewed it.

What is in this build

  • Browse the home page, categories, featured products and offers.
  • Search the shop, filter by category and price, sort and load more.
  • Product pages with variants, prices and offers; save items for later.
  • Cart, checkout with cash on delivery, and delivery addresses.
  • Create an account or sign in; orders with their progress and cancellation.
