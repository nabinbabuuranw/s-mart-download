Install

  1. Tap Download the app and wait for the bar to finish.
  2. Open the file from your Downloads.
  3. When Android asks, allow installs from this browser or file app.
  4. If Play Protect warns about an unknown app, choose Install anyway. This is a sideloaded build and Google Play has not reviewed it.

What is new in 0.2.0-m3

  • The official S Mart logo on the launcher icon and the splash screen.
  • S Mart colours (green and red, from the logo) in light and dark mode.
  • Search on Home with suggestions from the shop's catalogue.
  • Product photos swipe in a gallery when a product has more than one.
  • Category chips open the shop already filtered to that category.
